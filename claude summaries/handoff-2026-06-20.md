## What This Project Is

Original graded system: PIC16F877A + ESP8266 + Raspberry Pi — had reliability issues.  
Exhibition rework: replace entirely with ESP32 (sensor node) + Raspberry Pi (actuator controller) via Firebase RTDB.  
Flutter mobile app and Firebase schema are **unchanged** — zero app modifications needed.

**Critical rule:** Never touch graded artefacts: `pic-firmware/`, `esp-firmware/`, `default.hex`, `Report and Feasibilty Study/`.  
All exhibition work lives in `esp32-firmware/` and `exhibition/`.

---

## Architecture

```
ESP32 NodeMCU-32 v1.3
  → reads sensors every 2s
  → pushes to Firebase RTDB /sensors/

Firebase RTDB (embedded-project-32dca)
  /sensors/     ← ESP32 writes
  /commands/    ← app writes
  /status/      ← Pi writes
  /ai/          ← untouched
  /alerts/      ← untouched

Raspberry Pi (hostname: robox, user: robox)
  → polls Firebase every 1s
  → drives all actuators via GPIO
```

## What Is NOT Done (Next Steps in Order)

### Phase 3 — Wire ESP32 Sensor Side
**Needs: 2kΩ + 3kΩ resistors**

1. Check soil sensor wiring — currently reads 0% despite being connected. Verify VCC=3V3, GND, AOUT→P34.
2. Build ACS712 voltage divider: `ACS712_OUT → 2kΩ → P35`, junction `→ 3kΩ → GND`  
   (scales 5V ADC output to 3V max — safe for ESP32 P35)
3. Wire ACS712: VCC→5V, GND→GND, IP+/IP− in series with pump wire
4. In firmware: flip `CURRENT_ENABLED true`, reflash, verify serial shows current reading ~0.0A with no load

### Phase 4 — Wire Pi Actuator Side
**Needs: relay module, A4988 + stepper motor, 12V/6A SMPS, 4× LEDs + resistors, active buzzer, 2N2222 NPN transistors, 1N4007 diodes, 100µF cap**  
**Reference:** `exhibition/WIRING_DIAGRAM.md` — has exact pin-by-pin connections

Key wiring points:
- Pump relay: GPIO17 → 1kΩ → relay IN. Relay NO → 12V+, COM → pump+, pump− → SMPS GND
- A4988: GPIO27=STEP, GPIO22=DIR, GPIO23=ENABLE. VMOT→12V + 100µF cap. Set Vref BEFORE connecting motor (Vref = I_limit × 8 × Rsense)
- LEDs: GPIO24/25/16 → 220Ω → LED → GND. GPIO12 → 33Ω → blue LED → GND (or NPN+5V if dim)
- Buzzer: GPIO18 → 1kΩ → 2N2222 base. Collector → buzzer−. Buzzer+ → Pi 5V. Emitter → GND
- **Star ground:** pump− and A4988 PGND go directly to SMPS GND terminal. Pi GND joins at ONE point. Motor return current must never flow through Pi GND.

## Known Issues / Watch Out For

| Issue | Detail |
|---|---|
| Soil reads 0% | Sensor not properly wired or floating ADC. Fix in Phase 3. |
| Auto pump fires on boot | Because soil=0% in Firebase. Cooldown (60s) prevents infinite loop. Resolved once soil sensor wired. |
| Blue LED may be dim | Vf ≈ 3.0V for blue LEDs — 3.3V GPIO marginal. Use NPN + Pi 5V rail if dim. |
| Pi reboots when motor runs | Would mean star ground missing — motor return flowing through Pi GND. Check wiring carefully. |
| E-stop on boot | Was caused by stale `emergency_stop: true` in Firebase. Fixed: `init_firebase()` now seeds it to `false`. |
| `gpio` group doesn't exist | This Pi uses `dialout` group for `/dev/gpiomem`. robox already added. Do not try `usermod -G gpio`. |
